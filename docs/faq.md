# 常见问题

## 它会不会改坏我的 DSH 配置？

不会。本插件不写、不删、不改宿主的任何预设文件；所有配置存在插件自己的数据里，在装配期生效。卸载即恢复原状。

## 支持哪些环境？

纯 Web 版（`dsh --profile web`）与桌面版都支持——桌面版就是 Web 版加一层 Electron 壳，两边共用同一套 host 逻辑。

## 为什么某个预设的「提示词集」卡片是灰的？

那个预设声明了 `complete: true`，它的段清单由平台写死，插件无法改写。这类预设能配的只有工具面、技能面与快照开关。面板置灰并写明原因，是为了不让你误以为配置生效了。

## 为什么快照开关点不动？

该预设声明了 `includeRuntimeContext: false`，平台已经替它关掉了快照注入，开关没有可操作的空间。鼠标悬停问号可以看到说明。

## 一个工具集都不装会怎样？

等于**一个工具都不给**。这是本插件的语义边界：绑定即接管，没装就是空的。想让某个代理只给一个 shell，就建一个只勾 shell 的工具集；想让某个预设回到「平台全量下发」，就解除绑定。

## 和 dsh-context 是什么关系？

[dsh-context](https://github.com/bowenliang123/dsh-context) 用来查看模型这一轮实际收到了什么（提示词、工具、skill）。本插件决定投递什么，它负责事后核对，两个一起用刚好闭环。

## 卸载后配置去哪了？

卸载即恢复原状：宿主预设从头到尾没被改过，插件自己的数据随插件一起移除。

## 设置里没有出现「Agent 中心」？

先确认插件装在了正在使用的 profile 上（`web` 或 `desktop`），然后重启一次 DSH。还不行的话，确认你的 DSH 版本不是太旧——插件依赖宿主的一些较新的原语，太旧时可能挂载不上。

## 怎么反馈问题？

到 [GitHub 仓库](https://github.com/thissensen/dsh-agent-studio/issues) 提 issue。附上你的 DSH 版本、插件版本与复现步骤，能大幅加快排查。
